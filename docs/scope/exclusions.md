# Scope — Exclusions

> What Launchpad is deliberately not.

**Status:** Decided · **Updated:** 2026-09-22

## Decision

Launchpad is not:

1. a giant autonomous AI with no deterministic control
2. a replacement for GitHub, Linear or the model provider
3. a system that silently makes important product decisions
4. a chat history pretending to be product documentation
5. an untraceable code-generation machine
6. a system where every user shares one persistent agent context
7. a system where product intent disappears once coding begins
8. a central SaaS runtime where every customer's agents run through one shared Launchpad account
