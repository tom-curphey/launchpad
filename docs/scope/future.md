# Scope — Future

> Deliberately later work.

**Status:** Current plan · **Updated:** 2026-09-22

## Decision

1. **Voice.** This will be needed, but not first. It's another interface into the same Launchpad state: speech-to-text → conversational layer → Launchpad context, tools and agents → text-to-speech. Example commands: "What's blocked?", "What needs me?", "Why did we decide this?", "Approve that.", "Pause the SlackProperty agent."
2. **A PWA or native mobile app** on the same backend.
3. **Chat-app control** from Slack or WhatsApp, built as another interface on the same Launchpad API. It must not become a second source of state.
4. **Live verification**, which checks automatically that the intended change is actually live.
5. **Team features:** shared projects, permissions, budgets, audit. See [Business — Pricing](../business/pricing.md).
