# Scope — Priorities

> The current build order.

**Status:** Current plan · **Updated:** 2026-09-22

## Decision

1. **Coding from a phone is the headline goal.** Prioritise whatever makes "an agent works while I'm away, and I unblock it from my phone" real.
2. **The browser dashboard comes first.** It must be responsive. Mobile apps and voice come later.
3. **Prove the runtime early.** Run a small Eve test on one real case before building broadly: one Linear Ticket → a Dev Agent Run in a sandbox → a human question → an answer from a phone → resume → Pull Request.
4. **Incremental steps.** Move the existing codebase towards the target model in steps rather than rewriting it.
