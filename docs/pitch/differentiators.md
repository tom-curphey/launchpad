# Pitch — Differentiators

> Why Launchpad is different from a coding agent or a project management tool.

**Status:** Decided · **Updated:** 2026-09-22

## Decision

1. **It starts earlier.** A coding agent starts at *ticket/prompt → code*. Launchpad starts at *idea → Pitch → Product Definition → Decision Docs → planning → approved work*, and carries that intent through to development, review, UAT, deploy and live.
2. **It traces product to code.** Every Ticket Change traces back to a Decision.
3. **It's deterministic where it matters.** Orchestration is done by the Launchpad Engine, not an LLM.
4. **Humans control it remotely.** You can see and unblock every agent across every repository from a browser or phone.
5. **The customer controls the stack.** Customers bring their own AI provider, GitHub, Linear, Supabase and infrastructure.
