# Experience — Principles

> The principles every Launchpad experience must follow.

**Status:** Decided · **Updated:** 2026-09-22

## Decision

1. **Understandable.** A human can always see *why* work exists and *what* changed.
2. **Inspectable and traceable.** Every run, decision and change can be opened and traced.
3. **Controllable and interruptible.** Humans can pause, answer, reassign or reject at any point.
4. **Resumable.** Work continues from where it stopped after a human acts.
5. **Collaborative.** AI agents and Developers work in the same Workflow.
6. **Less prompting.** The flow is Product Definition → defined work → Workflow → agents execute → human intervenes only when needed → the system continues. It is never "keep prompting, keep asking what's next."
7. **Humans decide.** Humans define intent, review Draft Tickets, make decisions, resolve ambiguity, approve transitions, do UAT, review meaningful Pull Requests and decide what goes Live. AI does specialist execution within those boundaries.
