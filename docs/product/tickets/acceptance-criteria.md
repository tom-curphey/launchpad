# Tickets — Acceptance Criteria

> What acceptance criteria must define for Draft Tickets, Linear Tickets and UAT Checks.

**Status:** Decided · **Updated:** 2026-09-22

## Decision

Acceptance criteria answer: **what counts as correct?**

**For a Draft Ticket or Linear Ticket, they define:**

1. what the Ticket Change must do
2. what it must not do
3. behaviour that must stay unchanged
4. excluded work
5. relevant error behaviour
6. boundary conditions

**For UAT, they define:**

1. what the user should observe
2. correct behaviour
3. incorrect behaviour
4. what counts as PASS
