# Tickets — Ticket Change

> What a Ticket Change is and what it can include.

**Status:** Decided · **Updated:** 2026-09-22

## Decision

The Linear Ticket describes **what should be done**. The **Ticket Change** describes **what was actually changed**.

A Ticket Change may include code, configuration, database changes and migrations, infrastructure, external service configuration, design implementation and related artifacts. It is usually delivered as one Pull Request per Linear Ticket.
