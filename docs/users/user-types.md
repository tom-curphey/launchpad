# Users — User Types

> Who uses Launchpad.

**Status:** Current plan · **Updated:** 2026-09-22

## Decision

1. **A Launchpad installation belongs to one company.** Many people from that company use it.
2. **Everyone signs in with GitHub.** Their Launchpad role mirrors their GitHub role. See [Roles](roles.md).
3. **Human roles within a Project:**
   - the **human** defines intent, makes decisions and approves.
   - the **Developer** does development work. The same person can be both.
4. **Who adopts it:** companies and teams building several products or repositories with AI agents, who want to manage that work from anywhere, including a phone.
