## What is Launchpad?

**Launchpad** is an AI-assisted product development and project management platform that takes a product from idea to live.

**The PAD Method:**
- **P**itch — Define what you're building
- **A**ssemble — Turn it into a working product
- **D**eploy — Verify it and take it live

## Development

```bash
# Install dependencies
pnpm install

# Run dev server
pnpm dev

# Build for production
pnpm build
```
